# Constinex

Constinex — construction management ERP built on Odoo, for construction companies, general contractors, subcontractors, developers, and construction project management organizations.

This repository holds the Constinex landing page as a single self-contained file (`index.html`).

It was designed in Muse and exported on 2026-11-21. The page covers estimating and BOQ, CRM and contracts, procurement, subcontractors, site operations, equipment, project controls, quality and safety, finance, and customer portals — plus the Founding Customer Programme (free professional website + free software for the first three customers).
